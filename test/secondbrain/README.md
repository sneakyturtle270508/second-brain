# Test SecondBrain UI

This folder contains a static UI mock that resembles the Knowledge Base layout shown in your screenshot.

- ui.html: Static markup for the three-column layout (left rail, left panel with folders, right content with cards and files).
- styles.css: Styles to approximate the appearance (rounded cards, soft colors, subtle borders).
- ui.js: Tiny (non-essential) interactivity hook.

How to view
- Open test/secondbrain/ui.html in a browser.

How to reuse the real code
- If you want this test UI to reflect the actual secondbrain project, copy all files from the repository root into test/secondbrain and adjust paths as needed.
